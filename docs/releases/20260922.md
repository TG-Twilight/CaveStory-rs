# CaveStory-rs 20260922

首次公开发行。基于 doukutsu-rs，为 2004 年免费版《洞窟物语》提供简体中文、English、日本語的菜单与游戏资源体验。

## 下载选择

| 平台 | 架构 | 基础版 | 带游戏版 |
| --- | --- | --- | --- |
| Android | arm64-v8a | 文件名无 `_game` | 文件名有 `_game` |
| Android | armeabi-v7a | 文件名无 `_game` | 文件名有 `_game` |
| Windows | x86_64 | 文件名无 `_game` | 文件名有 `_game` |
| Windows | x86_32 | 文件名无 `_game` | 文件名有 `_game` |
| Windows | arm64 | 文件名无 `_game` | 文件名有 `_game` |

- 一般玩家可选择对应架构的 `_game` 包，包含中英日资源、字体及相关说明。Windows 解压后运行 `CaveStory-rs.exe`；Android 安装 APK 后自动离线准备资源。
- 基础版不包含原始游戏数据。Windows 需要兼容游戏资源及对应 Visual C++ 运行库；Android 在缺少资源时提供下载。
- Android 最低配置为 Android 7.0 / API 24，正式包名为 `io.github.cavestory_rs`。基础与带游戏版使用相同签名，可覆盖安装；旧 `io.github.doukutsu_rs` 是独立应用，不自动迁移存档。升级前请保留存档备份。
- `SHA256SUMS` 对应本页下载文件名；`verified-delivery.json` 记录包大小、哈希和架构核验结果。
- 本版 Windows 基础 ZIP 内 `README.txt` 的旧安装记录链接已撤下；请改看[当前安装说明](https://github.com/TG-Twilight/CaveStory-rs#play)。安装包内容与校验值保持不变。

## 本版内容

- 三语言菜单、剧情、物品说明、地图名称及图片资源切换；Android 自动跟随系统／应用语言，保留游戏内选择。
- Android 私有／公共存档目录选择与迁移，复制校验后切换并保留原件。
- 手柄热插拔、Xbox／PSP／自定义布局、原版／增强振动，以及可选的 Shizuku 蓝牙振动。
- Android 外设接入时自动隐藏触屏按键，无外设时恢复；可选的十秒无触摸隐藏默认关闭。
- 免费获取渠道提醒、三语言剧情提示和正式 Android 签名校验。外链须玩家明确确认；来源回答仅保存在本地。
- 编入本机 Trainer 接口，默认不允许连接。Windows 需主动启用；Android 需同签名 Trainer 的明确授权。独立修改器不包含在本次游戏发行中。
- 首次公开发行前补齐 APK 中的 Shizuku、引擎与 SDL 许可说明。

## 验证与限制

本次发行采用本地构建、签名并核验的五架构十包。GitHub Actions 自动构建与发布尚未完成适配，旧上游工作流已停用；本次上传不代表云端构建通过。

97 项 Rust、26 项 Python 资源及 6 项交付工具测试通过。发行校验覆盖 APK 签名／ABI／日期、Windows PE 架构／版本、基础与带游戏包的原生程序一致性、资源来源哈希、随包许可和个人存档排除。此前已有 Windows x64／x86 与 Android ARM64 运行验证；Android ARM32 有较早批次实机记录，Windows ARM64 尚无硬件验收。此次许可补包不新增手机实机验收。

完整通关、全部剧情校对、更多手柄／Android 版本、下载中断恢复、音频警告及 16 KB 页仍有待验证事项。详见[中文使用说明与已知限制](https://github.com/TG-Twilight/CaveStory-rs/blob/main/docs/README_zh-CN.md#status)，不将编译成功等同于所有设备兼容。
